# 毛球点心铺 · Acsus-Paws-Puffs

版本：2.1.1

这是 SillyTavern 可直接安装的运行文件仓库。

## 安装与更新

在 SillyTavern 的“扩展 → 安装扩展”中填写：https://github.com/Achenono/Acsus-Paws-Puffs
安装完成后刷新页面；后续在扩展管理中更新。
如已装旧仓版本，请先备份，并确认切换方案；不要重复安装两份点心铺。

更新前请备份 SillyTavern 数据，优先用测试聊天验证。
具体变化、已验证项目及手机/iOS 等未验证边界见 [发布说明](https://github.com/Achenono/Acsus-Paws-Puffs/releases)。

## 数据整理与备份

首次发现旧版点心铺数据时，点击“备份并整理”后自动保存完整旧设置备份并整理到当前用户文件；请勿刷新或关闭页面，等待提示完成。选择“稍后处理”保留原件，在扩展设置可继续整理。文件和酒馆设置核对后才移除对应旧字段；失败时保留原件并提供重试。
在点心铺设置的“关于 → 备份与恢复”中导出备份、选择单项或规划导入；核对清单后才确认写入。
导出默认清空 API 密钥和代理密码。勾选“包含密钥”及旧数据迁移备份可能含凭据，请自行妥善保管。
JSON 备份保留素材引用；图片、字体文件本体和酒馆原生聊天请另行备份。
使用 SillyTavern 数据清理工具时，请保留 acsus- 开头的点心铺数据及 st-theme-engine.json。
